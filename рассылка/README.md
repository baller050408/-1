# Рассылка

Сбор почт компаний **без сайта и без Telegram** из 2ГИС через официальный API.

## Файлы
- `collect_2gis.py` — сбор из 2ГИС (нужен ключ API).
- `collect_osm.py` — сбор из OpenStreetMap (бесплатно, без ключа): `python3 collect_osm.py --city "Казань"`.
- `emails.csv` — база: почта, название, адрес, телефон, рубрика (пока пустая — заполняется скриптом).
- `emails.txt` — только почты, по одной на строку (создаётся скриптом).
- `шаблон_письма.txt` — шаблон холодного письма.

## Запуск
1. Получить ключ на https://dev.2gis.com (Places API).
2. Выполнить:
   ```bash
   python3 collect_2gis.py --key ВАШ_КЛЮЧ --city "Казань" \
       --query "салон красоты" --query "автосервис" --query "кафе"
   ```
   Повторные запуски дописывают новые почты без дублей.

## Почему не Google и Яндекс
- **Google Maps / Places API** не отдаёт email вообще.
- **Яндекс Карты** — API организаций платный, email тоже не отдаёт; парсинг сайта запрещён правилами.
- В 2ГИС почта указана примерно у 10–30% компаний — это нормально.

(штраф юрлицам до 500 тыс. ₽). Пишите персонально, небольшими партиями,
